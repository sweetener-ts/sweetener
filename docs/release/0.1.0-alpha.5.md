# Sweetener 0.1.0-alpha.5

This alpha fixes two integration rough edges. Package names, entry points,
language version, and format versions remain unchanged from alpha.4.

## Integrations

- `@sweetener/node/register` no longer prints Node's `DEP0205` deprecation
  warning on Node 26. There it installs its hooks with
  `module.registerHooks()`; on Node 24 and 25, where `registerHooks` is still a
  release candidate, it keeps `module.register()`. The hooks are now
  synchronous, so the same pair serves both.
- `@sweetener/prettier-plugin` lays out lines in macro-definition files, not
  only their indentation. It collapses runs of spaces within a line, drops
  trailing spaces, puts a space between a name or `)` and the `{` after it, and
  moves a closing `}` onto its own line when its block opened onto one. Every
  change keeps the file's tokens, and whether each one begins a line, as they
  were.
